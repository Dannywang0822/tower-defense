# 路卫 — Coinpath Defense

HTML5 竖屏塔防：守城塔 vs 僵尸怪，沿「几」字形路径刷波。程序化 **1000 关** 战役、四档难度、可选地图风格、地图阶递进；三塔建造 / 升级 / 卖塔，倍速、暂停、选关与速清金币奖励。

## 怎么玩

1. **选难度 + 地图** — 开局分别点选难度（巡城 / 固守 / 血战 / 绝境）与地图风格（暮城 / 枯墓 / 雪原 / 熔岩 / 毒沼），再出征。
2. **放塔** — 点空地选箭塔 / 炮塔 / 霜塔（路径格不能放）。
3. **升级 / 卖塔** — 点已有塔可升级或卖掉（返还约当前投入的 60%）。
4. **波次** — 自动刷怪或点「下一波」提前开始（可获少量等待奖励金）。
5. **倍速** — 顶栏 1×–4×；只加快动画，**不缩短**速清结算用的墙钟时间。
6. **暂停** — 「暂停」冻结战斗；可「继续」或「返回选关」（返回时会留下「继续战斗」快照）。
7. **选关 / 继续** — 回到难度+地图+关卡选择；若有未结算战斗，可点「继续战斗」原样恢复。通关/失败/新开一局会清掉该快照。
8. **技能** — 每关开局从 3 个随机技能中选 2 个带入（火雨 / 援军 / 沙漏 / 雷击 / 金潮）；开局就绪，强度随地图阶提升。
9. **速清奖励** — 本波首怪出现到清完（或漏光）的实际秒数越短，额外金币越高（封顶约 36；拖太久为 0）。
10. **章节** — 每 30 关一章，章名在开始屏和顶栏。第 30 / 60 / 90 / 120 关的最后一波是章节首领（护盾、变速、召援等，不只是加血）。
11. **进化** — 3★ 之后把材料塔拖到金框目标上。四式配方见下表，建造栏「配方」可查看；未通关第 1 章时图鉴上锁，但拖对材料会发现。

### 三塔一览（造价固定）

| 塔 | 造价 | 特点 |
|---|---|---|
| 箭塔 | 50 | 单体、便宜铺场 |
| 炮塔 | 120 | 溅射清线 |
| 霜塔 | 90 | 减速控场 |

升级：Lv1→2 约原价×0.8（伤↑、射速↑）；Lv2→3 约原价×1.2（伤↑、射程↑）。霜塔减速幅度随等级略增（上限约 50%）。

## 战役与难度

- **1000 关** × 每关 **30 波**（波型模板复用原 1–30，再乘难度/地图阶系数）
- HUD：关卡 `level/1000`、章节名、波次 `w/30`、生命、金币、当前难度
- 通关本关 30 波 → 下一关；第 1000 关清完且生命＞0 → 全通胜利
- 生命 ≤0 → 本关失败，可重开或返回选关

### 难度档

| 档 | 怪血 | 怪速 | 赏金 | 开局金 | 生命 |
|---|---|---|---|---|---|
| 巡城 | ×1 | ×1 | ×1 | 120 | 20 |
| 固守 | ×1.25 | ×1.08 | ×1.05 | 120 | 20 |
| 血战 | ×1.55 | ×1.15 | ×1.1 | 140 | 20 |
| 绝境 | ×2.0 | ×1.22 | ×1.15 | 160 | 15 |

### 地图阶

`stage = floor((level - 1) / 30) + 1`：每通关 **30 关**升一章——路径更弯更密，怪血/速/数量随阶递增。前四章：荒原哨站、雾港码头、熔城裂隙、霜冠高原（之后循环）。`level % 30 == 0` 的第 30 波终局 Boss 换成该章首领（多阶段机制），血量仍沿用原里程碑乘子。

后期解锁怪种示例：盾兵、飞影、分裂蛛、治疗虫、闪现贼等（随阶开放）。地图饰物（暮城 / 枯墓 / 雪原 / 熔岩 / 毒沼）仍在开始屏自选；地块与路径的主色跟章节走。通关后解锁的章节色是可叠加妆点。

### 进化（3★ 之后）

拖材料到 3★ 目标（不是永久天赋）：

| 配方 | 材料 | 效果 |
|---|---|---|
| 霜矢哨 | 3★ 箭（任意专精）+ ≥2★ 霜 | 命中短减速，伤害 +15% |
| 破城臼 | 3★ 炮 + 另一座 ≥2★ 炮 | 溅射更大，坦克额外受伤 |
| 永冻塔 | 3★ 霜（冰封）+ ≥2★ 箭 | 减速上限提高，击杀冰爆 |
| 连天弩 | 3★ 箭（连弩）+ 另一座同星箭 | 射速与矢数提高，约 +25% |

卖出仍约为累计投入的 60%。配方按钮在建造栏。

同关同难度使用固定 `seed`，便于重开对照。设计摘要见 [DESIGN.md](DESIGN.md)，视觉说明见 [VISUAL_NOTES.md](VISUAL_NOTES.md)。

### ?v=20 — 章节世界 · 塔进化配方（本版）
- **章节世界**：`stage = floor((level-1)/30)+1` 不变，千关波次生成不改。第 1–4 章为荒原哨站 / 雾港码头 / 熔城裂隙 / 霜冠高原，之后按这四套地貌循环（名称加周次）。地块与路径色、入口氛围、怪物色调随章节变；开始屏自选地图仍只改饰物（砖缝/墓碑等）。
- **章节首领**：仅 `level % 30 === 0` 的第 30 波，原终波 Boss 换为章节首领（尘骸督军 / 雾锚巨骸 / 熔核领主 / 霜冕尸王）。血量仍用原来的里程碑乘子，难度来自两段机制：护盾、潮汐变速、熔怒光环、回血召卫、霜凝城塔等。普通 Boss 与非终波数值不动。
- **章节色**：通关第 1 章（可玩到第 31 关）解锁雾港妆点，依此类推。妆点叠在当前章节地貌上，不改首领种类。HUD 与开始屏显示章节名。
- **塔进化**：3★ 之后把材料塔拖到目标上（金框=可进化，绿框=可合成）。四式配方——霜矢哨（短减速）、破城臼（更大溅射 / 克坦克）、永冻塔（减速上限 + 冰爆）、连天弩（更高射速多矢，相对连弩约 +25%）。进化塔外观单独绘制。卖出仍约为总投入的 60%。未进化塔的 `towerStats` 不变。
- **图鉴**：建造栏「配方」。通关第 1 章后四式全部点亮；未通关时拖对材料也会发现并记入存档。
- 继续战斗快照升为 v20，仍可读 v18 快照。

### ?v=19 — 修复拖拽合成卡死
- **根因**：`?v=18` 重构技能池时误删 `mergeBlockReason` / `feedMerge` / `openBranchPicker` 等函数；拖塔时 `draw()` 抛 `ReferenceError`，主循环中断 → 关卡假死、合成无响应。
- 已恢复拖拽合成与 3★ 专精选择；失败拖放仍 toast 原因并放回原位。
- 防御：`pointercancel` / `blur` / 暂停时清拖拽态；主循环 try/catch，单帧异常不再整局卡死。

### ?v=17 — 拖拽合成 · 塔外观大改
- 合成改为**拖拽**：按住一座塔拖到另一座**同种、同星、双方 Lv≥2** 的塔上松手即合成；仍为 3 合 1——每次喂入目标获得 1 格进度（塔右侧绿点 1/3→2/3），第 3 座拖入时升星（新塔 Lv1，投入累计，卖出仍 60%）。
- 拖拽中：半透明塔跟手，可合成目标绿框，同种不合规目标红框；拖到空地/无效目标自动放回。轻点仍打开升级/卖出/专精面板。
- 塔外观：箭塔=绿尖顶方形高箭楼+弩；炮塔=八角矮碉堡+橙色炮管；霜塔=六角符文台+悬浮冰晶。
- 等级差异：Lv1 木质 / Lv2 石质 / Lv3 金属金边，体积随等级增大、底座层数=等级、炮管数与侧冰晶随等级增加，左上角 Lv 标。
- 星级差异：2★ 银色虚线环+双旗，3★ 金色旋转光环+环绕光点+金旗，底部星章。
- 专精外观：连弩三联弩臂、狙击长弩+瞄镜红点、迫击粗短臼炮、燃烧喷火炮口、冰封冰块核心、碎冰旋转冰刺。
- 纯视觉改动，数值不变。

### ?v=16 — 三合一升星 · 专精 · 主动技能
- **合成**：同种同星且 Lv≥2 的 3 座塔点选合成升星（最高 3★）；合成后 Lv 重置为 1，投入合并，卖出仍返 60%。
- **星级乘子**：2★ 伤×1.8 射速×1.1；3★ 伤×3.2 射速×1.2 射程+0.3；星内 Lv1–3 升级保留。
- **3★ 专精**：箭塔连弩/狙击；炮塔迫击/燃烧；霜塔冰封/碎冰（本关永久）。
- **主动技能**：流星火雨（CD60，点地图释放）、援军（CD45，路径拦怪）；强度随地图阶提升；开局就绪。
- **平衡**：stage≥4 怪血额外 ×1.15。难度/地图双选、暂停、倍速、速清、音效保留。
