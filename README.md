# 路卫 — Coinpath Defense

HTML5 竖屏塔防：守城塔 vs 僵尸怪，沿「几」字形路径刷波。程序化 **1000 关** 战役、四档难度、地图阶递进；三塔建造 / 升级 / 卖塔，倍速、暂停、选关与速清金币奖励。

## 怎么玩

1. **选难度** — 开局选「巡城 / 固守 / 血战 / 绝境」，再开一局。
2. **放塔** — 点空地选箭塔 / 炮塔 / 霜塔（路径格不能放）。
3. **升级 / 卖塔** — 点已有塔可升级或卖掉（返还约当前投入的 60%）。
4. **波次** — 自动刷怪或点「下一波」提前开始（可获少量等待奖励金）。
5. **倍速** — 顶栏 1×–4×；只加快动画，**不缩短**速清结算用的墙钟时间。
6. **暂停** — 「暂停」冻结战斗；可「继续」或「返回选择难度」。
7. **选关** — 随时回难度/关卡选择；进度写入浏览器 `localStorage`。
8. **速清奖励** — 本波首怪出现到清完（或漏光）的实际秒数越短，额外金币越高（封顶约 36；拖太久为 0）。

### 三塔一览（造价固定）

| 塔 | 造价 | 特点 |
|---|---|---|
| 箭塔 | 50 | 单体、便宜铺场 |
| 炮塔 | 120 | 溅射清线 |
| 霜塔 | 90 | 减速控场 |

升级：Lv1→2 约原价×0.8（伤↑、射速↑）；Lv2→3 约原价×1.2（伤↑、射程↑）。霜塔减速幅度随等级略增（上限约 50%）。

## 战役与难度

- **1000 关** × 每关 **30 波**（波型模板复用原 1–30，再乘难度/地图阶系数）
- HUD：关卡 `level/1000`、波次 `w/30`、生命、金币、当前难度
- 通关本关 30 波 → 下一关；第 1000 关清完且生命＞0 → 全通胜利
- 生命 ≤0 → 本关失败，可重开或返回选关

### 难度档

| 档 | 怪血 | 怪速 | 赏金 | 开局金 | 生命 |
|---|---|---|---|---|---|
| 巡城 | ×1 | ×1 | ×1 | 120 | 20 |
| 固守 | ×1.25 | ×1.08 | ×1.05 | 120 | 20 |
| 血战 | ×1.55 | ×1.15 | ×1.1 | 140 | 20 |
| 绝境 | ×2.0 | ×1.22 | ×1.15 | 160 | 15 |

### 地图阶

`stage = floor((level - 1) / 30) + 1`：每通关 **30 关**升一阶——路径更弯更密，怪血/速/数量随阶递增；Boss 更肉。阶老板关（`level % 30 == 0`）终局 Boss 再加强。

后期解锁怪种示例：盾兵、飞影、分裂蛛、治疗虫、闪现贼等（随阶开放）。场景皮肤按阶轮换：暮城 / 墓园 / 雪原 / 熔岩 / 毒沼（仅视觉）。

同关同难度使用固定 `seed`，便于重开对照。设计摘要见 [DESIGN.md](DESIGN.md)，视觉说明见 [VISUAL_NOTES.md](VISUAL_NOTES.md)。

## 本地运行

```bash
cd /path/to/tower-defense
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080/ （或带 `?v=13`）。无需构建步骤，纯静态 HTML / CSS / JS。
