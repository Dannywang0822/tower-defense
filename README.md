# 路卫 — Coinpath Defense

HTML5 竖屏塔防：守城塔 vs 僵尸怪，沿「几」字形路径刷波。程序化 **1000 关** 战役、四档难度、可选地图风格、地图阶递进；三塔建造 / 升级 / 卖塔，倍速、暂停、选关与速清金币奖励。

## 怎么玩

1. **选难度 + 地图 + 关卡** — 难度（巡城 / 固守 / 血战 / 绝境）与地图皮肤自选。关卡决定**章节世界**（每 30 关一章）：边关尘道、霜河关、雷岩裂谷、王城夜围；第 5 章起主题循环，数值仍按地图阶走。
2. **放塔** — 按住建造栏的箭塔 / 炮塔 / 霜塔，拖到空地松手。轻点按钮可预览射程，再点空地也能放。路径、占用或金币不足会取消。
3. **升级 / 卖塔** — 点已有塔可升级或卖掉（普通塔返还约当前投入的 60%）。进化塔只可再强化 1 次（150 金），出售为两座材料总投入的 50%。
4. **波次** — 自动刷怪或点「下一波」提前开始（可获少量等待奖励金）。
5. **倍速** — 顶栏 1×–4×；只加快动画，**不缩短**速清结算用的墙钟时间。
6. **暂停** — 「暂停」冻结战斗；可「继续」或「返回选关」（返回时会留下「继续战斗」快照）。
7. **选关 / 继续** — 回到难度+地图+关卡选择；若有未结算战斗，可点「继续战斗」原样恢复。通关/失败/新开一局会清掉该快照。
8. **技能** — 每关开局从 3 个随机技能中选 2 个带入（火雨 / 援军 / 沙漏 / 雷击 / 金潮）；开局就绪，强度随地图阶提升。
9. **速清奖励** — 本波首怪出现到清完（或漏光）的实际秒数越短，额外金币越高（封顶约 36；拖太久为 0）。
10. **章节 Boss** — `level` 为 30 的倍数时，第 30 波 Boss 换成该章首领（砂酋 / 冰甲卫 / 裂谷龙 / 夜王），各有多段机制，不只是加血。
11. **塔进化** — 通关第 1–4 章分别解锁配方。把符合条件的两座 3★ 塔拖到一起进化（不可再合成、不可再升星）。
12. **动态难度** — 每波开始按当场强度算压力。强则加压（怪更肉、稍快、少量精英替换），漏怪或偏弱则减压。战斗状态显示「加压 / 减压 / 平稳」。
13. **音乐** — 跟所选地图皮肤走，进战斗也不会被关卡章节盖掉：暮城与毒沼是尘道，枯墓是夜围，雪原是霜河，熔岩是裂谷。暂停时压低。静音按钮同时关掉背景和音效，背景音量低于技能音效。

|---|---|---|

## 战役与难度

- **1000 关** × 每关 **30 波**（波型模板复用原 1–30，再乘难度/地图阶系数）
- HUD：关卡 `level/1000`、波次 `w/30`、生命、金币、当前难度
- 通关本关 30 波 → 下一关；第 1000 关清完且生命＞0 → 全通胜利
- 生命 ≤0 → 本关失败，可重开或返回选关

### 难度档

| 档 | 怪血 | 怪速 | 赏金 | 开局金 | 生命 |
|---|---|---|---|---|---|
| 巡城 | ×1 | ×1 | ×1 | 120 | 20 |
| 固守 | ×1.25 | ×1.08 | ×1.05 | 120 | 20 |
| 血战 | ×1.55 | ×1.15 | ×1.1 | 140 | 20 |
| 绝境 | ×2.0 | ×1.22 | ×1.15 | 160 | 15 |

### 地图阶

`stage = floor((level - 1) / 30) + 1`：每通关 **30 关**升一阶——路径更弯更密，怪血/速/数量随阶递增；Boss 更肉。阶老板关（`level % 30 == 0`）终局 Boss 再加强，并换成该章章节 Boss。

怪的最终血量 / 速度 = 波次模板 × 难度档 × 地图阶 × 动态系数（只乘这一次，有上下限）。怪的数量不因动态难度减少。

后期解锁怪种示例：盾兵、飞影、分裂蛛、治疗虫、闪现贼等（随阶开放）。地图视觉皮肤（暮城石砖 / 枯墓雾夜 / 冰霜雪原 / 熔岩裂隙 / 毒沼荒原）由玩家在开始屏自选，整关沿用；地图阶只影响路径难度与怪系数，不强制换皮。

同关同难度使用固定 `seed`，便于重开对照。设计摘要见 [DESIGN.md](DESIGN.md)，视觉说明见 [VISUAL_NOTES.md](VISUAL_NOTES.md)。

|---|---|---|---|
| 1 | 边关尘道 | 土黄 | **砂酋**：70% 血召唤 4 只快跑；30% 遁地 2 秒不可选中，再从路径前方钻出 |
| 2 | 霜河关 | 青白 | **冰甲卫**：每掉 20% 血给全场护盾（吸收量 = Boss 最大生命 8%）；护盾碎裂时全体塔射速 ×0.5，持续 1.5 秒 |
| 3 | 雷岩裂谷 | 紫黑 | **裂谷龙**：A 头沉默最贵的塔 4 秒，B 头沿路径灼烧 2 秒，约每 8 秒换头；45% 血以下两头一起放 |
| 4 | 王城夜围 | 暗红 | **夜王**：66% / 33% 换阶段外观，清掉自身减益并加速 15%；阶段 3 每 8 秒召 6 只混编 |

### 进化配方

材料拖到另一座符合条件的 3★ 上。通关第 N 章（该难度进度打过 `N×30` 关）解锁第 N 条。

| 配方 | 材料 | 效果 |
|---|---|---|
| 贯星弩 | 3★ 狙击箭 + 3★ 连弩箭 | 沿瞄准方向穿透最多 5 个目标，最后一击不衰减 |
| 狱火臼 | 3★ 迫击炮 + 3★ 燃烧炮 | 落地留火 3 秒；落点已在火上时爆炸半径 +40%；射速 ×0.9 |
| 绝对零度 | 3★ 冰封霜 + 3★ 碎冰霜 | 减速固定 50%，冻结率 18%，冻结结束造成 `80×S` 爆裂 |
| 破城连弩炮 | 任意 3★ 箭 + 任意 3★ 炮 | 交替射出优先飞影/盾的箭，以及溅射炮 |

进化塔不能再合成或升星。等级可再强化 1 次，花费 150。出售返还两座材料投入之和的 50%。

### 动态难度

每波开始计算 `P`（0–1），加压与减压互斥：

`P = clamp(0.45×星级分 + 0.25×进化分 + 0.15×经济分 + 0.15×速清分 − 0.20×漏怪分, 0, 1)`

- 加压 `P>0.55`：血 ×(1+0.18p)，速 ×(1+0.06p)，约 10%×p 的普通怪升为精英。Boss 波加压减半。
- 减压 `P<0.40`：血 ×(1−0.22m)，速 ×(1−0.08m)，赏金 ×(1+0.15m)。连续两波漏怪时，下一波减压至少 0.5，并不再加压。
- 中间带两者都不生效。
